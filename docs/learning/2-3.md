# Story 2.3: Tenant isolation is tested on every pull request

## What was built
- `ActorDep` now runs every logged-in route inside `tenant_scope(actor.business_id)`. A new **async** dependency, `actor_in_tenant_scope`, does it.
- `NotFound` (404, code `not_found`) and `TenantRepository.get_or_raise(id)`. "Missing" and "another Business's" give the same answer.
- A tenant-isolation suite (`pytest -m isolation`). Every endpoint must be on one list: `NO_TENANT_DATA` (with a reason) or `ISOLATION_CHECKS` (with a cross-Business test).
- Schema guards: every tenant table needs `UNIQUE (business_id, id)`, and a link to a tenant table must use both columns (a composite foreign key).
- Code guards: no tenant repository method takes `business_id`. Ruff bans `text()` / `TextClause` outside `app/core`.
- CI: a step named "Tenant isolation suite (FR-11)" runs before the full test run.

## Why
- One Business must never see or change another Business's data (FR-11). Each guard closes one way a leak could happen.
- 404, not 403. A 403 says "this exists, but it is not yours", which leaks that the record exists.
- Guards that fail by themselves beat a rule that people must remember.

## Data flow
Request with cookie → `get_actor` (sync; cookie → Actor) → `actor_in_tenant_scope` (async; sets the Business in a ContextVar) → route runs; repositories add `WHERE business_id = current_business_id()` → `get_or_raise` finds nothing for another Business's id → `NotFound` → error handler → 404 `{"error": {"code": "not_found", ...}}` → route returns → the scope is cleared.

## Concepts learned
1. ContextVar and threads. A sync dependency runs in a worker thread, so a value it sets is lost. An async dependency runs in the request's own task, and that context is copied into the route's thread.
2. 404-not-403. Do not tell an attacker that a record exists.
3. Composite foreign key. Link on `(business_id, id)`, so the database itself refuses a cross-Business link.
4. Positive control. A test that proves the tool can really write, so "nothing changed" means something.
5. Prove the guard bites. Break the code on purpose, see the test fail, then undo.

## Surprises
- FastAPI 0.162 keeps included routers as `_IncludedRouter` boxes in `app.routes`, so a plain loop finds no API routes. The suite uses `fastapi.routing.iter_route_contexts`, the public helper FastAPI's own OpenAPI code uses.
- The docs helper path is `/docs/oauth2-redirect`, not under `/api`.
- WSL hung once (`0x8007274c`). Fix: quit Docker Desktop, `taskkill /f /im wslservice.exe` as admin, `wsl --shutdown`.
